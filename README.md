# WS Tech Support

Standalone bilingual WaterSense and Yunnan technical support matrix.

The site is a single static HTML page. Open `index.html` locally or deploy the repository root to a static host. Styling loads Tailwind CSS and Font Awesome from public CDNs; no build step or environment variables are required.

Source: `Yunnan2 Tech support Sep 23.html` (copied to `index.html` for hosting). The original local file is not modified.
